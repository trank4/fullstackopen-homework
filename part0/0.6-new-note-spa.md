# Exercise 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: The user writes a note and clicks Save
    Note right of browser: The JavaScript adds the note to the list and redraws it

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa (JSON: content, date)
    activate server
    Note left of server: If accepted, the server adds the new note to the notes array
    server-->>browser: Status code 201 if accepted, 400 if rejected
    deactivate server

    Note right of browser: If rejected, the JavaScript removes the note and redraws the list
```
